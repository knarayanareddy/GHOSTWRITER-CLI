# ADR-008: RFC 2119 normative language in spec

**Status:** Accepted
**Date:** 2026-06-12

## Context

Requirements must be testable.

## Decision

Interpret MUST/SHOULD/MAY per RFC 2119 in the design specification.

## Consequences

- Reviewers can block merges for violated MUST requirements.
- This ADR is retained as part of the permanent architecture record.
