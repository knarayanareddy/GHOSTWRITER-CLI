# ADR-001: Local-first architecture (no cloud backend)

**Status:** Accepted
**Date:** initial

## Context

GhostWriter stores and processes corpus data only on the user machine.

## Decision

Build a local-only CLI; do not add a cloud control plane or telemetry backend.

## Consequences

- Private corpus data stays under user control; publish network calls are explicit.
- This ADR is retained as part of the permanent architecture record.
