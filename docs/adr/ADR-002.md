# ADR-002: Ollama as sole LLM backend for v1.0

**Status:** Accepted
**Date:** initial

## Context

MVP needs local model inference without cloud API exposure.

## Decision

Use Ollama over loopback as the only generation backend for v1.0.

## Consequences

- Simplifies privacy guarantees while limiting backend choice.
- This ADR is retained as part of the permanent architecture record.
