# ADR-006: Prompt-layer voice injection (no fine-tuning)

**Status:** Accepted
**Date:** initial

## Context

Fine-tuning local models is out of MVP scope.

## Decision

Generate natural-language style instructions from metrics and include them in prompts.

## Consequences

- Fast and private, but less precise than model fine-tuning.
- This ADR is retained as part of the permanent architecture record.
