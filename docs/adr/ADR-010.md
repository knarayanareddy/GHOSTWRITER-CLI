# ADR-010: pyproject.toml (PEP 621) as sole build config

**Status:** Accepted
**Date:** 2026-06-12

## Context

Packaging should have one canonical config.

## Decision

Use pyproject.toml for build metadata, dependencies, test/lint tool configuration.

## Consequences

- Avoids setup.py/setup.cfg drift.
- This ADR is retained as part of the permanent architecture record.
