# ADR-011: Zero telemetry — non-negotiable product stance

**Status:** Accepted
**Date:** 2026-06-12

## Context

User trust depends on no hidden network behavior.

## Decision

Do not collect analytics, crash reports, beacons, or automatic update checks.

## Consequences

- Operational visibility is local logs and user-initiated doctor reports only.
- This ADR is retained as part of the permanent architecture record.
